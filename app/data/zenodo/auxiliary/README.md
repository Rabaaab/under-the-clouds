# Auxiliary data

This folder contains external reference datasets used for cross-validation
of the SAR Morocco Flood Dataset water masks.

## Files

### JRC_occurrence_Zone1_KsarElKebir.tif

- **Source**: JRC Global Surface Water Explorer (Pekel et al., 2016)
- **Dataset**: JRC Monthly Water History v1.4
- **Coverage**: Ksar El Kebir area (matches Zone 1 extent)
- **Description**: Per-pixel water occurrence percentage (0-100%)
  computed from Landsat archive (1984-2020)
- **Purpose**: Independent reference for validating the HSBA-generated
  water masks in permanent water bodies (rivers, reservoirs)

## Reference

Pekel, J.-F., Cottam, A., Gorelick, N., Belward, A.S., 2016.
High-resolution mapping of global surface water and its long-term changes.
Nature 540, 418-422. https://doi.org/10.1038/nature20584
